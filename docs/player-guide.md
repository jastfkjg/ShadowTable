# 玩家指南

[返回项目首页](../README.md) · [规则说明](rules.md) · [积分系统](scoring.md)

桌边助手用于面对面阿瓦隆聚会：讨论、盘刀和最终胜负判断在线下完成，线上负责私密发牌、秘密提交与操作结算。具体板子和人数见 [支持的玩法](../README.md#支持的玩法)。

## 从进桌到再开一局

| 阶段             | 玩家操作                                       | 房主操作                                           |
| ---------------- | ---------------------------------------------- | -------------------------------------------------- |
| 创建／加入       | 通过邀请或 6 位房间码进入，首次进桌确认昵称    | 选择人数与板子，邀请朋友                           |
| 入座／准备       | 选择空位、准备；可换座、站起围观或选择回避角色 | 设置板子、人数、湖仙与计分，等待满座且全员准备     |
| 发牌／讨论       | 主动查看自己的身份、视野，面对面讨论           | 发牌，按现场进度发起操作                           |
| 投票／任务／技能 | 按提示秘密提交，等待收齐后结算                 | 选择操作、队员或失败票门槛，查看提交进度           |
| 结束／重开       | 查看本人战绩与可用复盘，重新准备               | 线下盘刀后登记结果，或选择“不计战绩”；重开同一牌桌 |

系统不会因三次任务成功／失败、连续否决或单次操作结果自动结束整局。当前小程序没有刀梅林入口，最终盘刀在线下进行；房主负责登记结算结果。

### 邀请与旁观

房间内“邀请好友”和微信右上角转发均分享当前牌桌。邀请包含房间号与创建时间，避免解散后房间号复用，让旧邀请进入另一张牌桌。

已有昵称的新成员可直接加入，首次用户在目标房间确认昵称；原成员恢复座位。准备阶段满座、游戏进行中及本局结束后，新成员均先旁观，不获得身份、不参与秘密提交、不计入本局战绩。开局后参赛名单锁定，重开后旁观者可手动选择空位入座。

### 等待与中断

- 房主可以确认“结束等待”：未提交的投票记弃权，技能按本次不使用处理，任务或必选目标操作作废。
- 切换未结算操作前需确认作废，已经发放的身份与已结算记录保留。
- 网络结果不确定时，使用原请求编号重试，避免重复执行；恢复连接后先核对操作状态。
- 结束本局不会额外公开全员身份。

## 管理我的牌桌

返回大厅或切换牌桌会保留当前座位，不等于离开房间。首页展示牌桌状态、人数、座位和最近活动，支持复制房间码、更多菜单及移动端左滑操作。

| 操作               | 作用                                                                   |
| ------------------ | ---------------------------------------------------------------------- |
| 个人备注           | 最多 30 字，仅自己可见，保存在服务端                                   |
| 移除记录           | 确认后仅隐藏自己的列表条目，重新进入后恢复                             |
| 离开房间           | 按当前游戏规则退出并释放座位                                           |
| 解散房间           | 仅房主可执行，需确认，影响所有成员并删除房间内过程；已归档个人战绩保留 |
| 转交房主／移出玩家 | 房主可转交管理权；准备阶段或本局结束后可移出成员                       |

进行中、待开局的牌桌优先展示；最近 72 小时有活动的已结束／已终止牌桌，按全房最近活动倒序最多展示 3 桌，其余有效牌桌收进“历史牌桌”。已结束／已终止牌桌满 72 小时无活动后失效，不能再进入或重开；失效、已解散和已离开的牌桌自动从列表隐藏，战绩与已归档复盘保留。其他数据保留周期见 [维护说明](operations.md)。

## 个人资料与账号

“对局 / 我的”分别用于牌桌与个人资料；进入牌桌后隐藏底部导航。“我的”可查看战绩、积分、趣味记录、荣誉徽章、排行榜与月度战报。

- **昵称**：首次创建或加入牌桌时确认个人昵称，可快捷填写微信昵称或自由输入。之后默认带入；临时修改本桌昵称只影响当前牌桌。
- **头像**：提供 160 款内置头像，经典线稿、彩色蜡笔、黑白简笔、极简几何、像素风各 32 款。选择后点击“保存资料”生效。服务端可选开启 [自定义头像上传](avatar-uploads.md)，审核并保存后同步到牌桌、排行榜和网页版。
- **账号同步**：小程序沿用微信身份。网页版默认游客；服务端开启 [小程序扫码确认登录](web-login.md) 后，可在网页“我的”使用同一账号，共用资料、战绩、积分与座位。游客历史不自动合并，原游客凭证失效后无法自动找回。
- **开发账号**：本地开发登录每次新登录生成独立身份，清除会话后不能恢复原身份。

## 战绩、积分与复盘

“我的战绩”通过“统计 / 对局记录 / 趣味记录”三个页签切换，保留筛选、展开状态与各自浏览位置。

### 统计与对局记录

统计按阵营和角色展示局数、胜率、胜场及积分，点击角色或阵营可查看详情。对局记录可组合筛选时间、板子、结算角色、胜负，以及计分局与趣味条件；筛选覆盖全部历史记录。近 7 天／近 30 天包含当日，按北京时间自然日计算。

胜率仅统计有明确胜负、身份完整的有效参赛局，按**结算时最终阵营**判断个人胜负。终止局、未登记胜负和身份不完整的局不计入，旁观者没有参赛战绩。人工登记与系统判定会标记来源，缺失的身份、过程和胜方保留为未记录，不作推测。

陪测账号（`test:`）不保存个人战绩、积分或趣味记录，纯陪测对局不归档；有陪测参与时，真实玩家和开发账号的有效成绩正常保存。统计资格与回避卡自动奖励资格分别判断，测试用途的对局不参与自动发卡。

### 月度积分

积分适用于经典基础 5–10、12 人，以及十二骑士 10、11、12、13 人。房主可在准备阶段通过“房间设置 → 积分 → 本局计分”切换，发牌后固定；关闭计分仍可保存正常胜负战绩。

积分按北京时间自然月及对局结束时间统计，每月 1 日零点当前积分从零开始，历史对局与流水保留。独立调分按操作时间归属，更正旧对局仍影响原月份。当月首次进入“我的”会展示上月回顾，新账号首月不提示；确认后跨设备与重启不重复提醒。

“积分明细”只列本月流水，区分对局得分与独立调整，零分计分局保留；点击计分对局可查看详情。旧对局不自动补算积分。分值、MVP / SVP 奖励与更正规则见 [积分系统](scoring.md)。

### 对局复盘与同房战绩卡

支持复盘的对局按轮次展示过程，可切换全局／我的视角，查看玩家初始身份、最终身份和变化轨迹；历史资料不足时明确标为未记录。

在准备阶段点击其他已入座玩家，或在游戏中点击自己／其他玩家，可打开战绩卡；准备阶段点击自己的座位仍为确认站起。战绩卡仅展示历史局数、胜场、胜率、阵营表现、当前积分和已佩戴徽章，不返回本局私密身份或完整历史明细。排行榜与月报入口也可打开共用战绩卡。

## 排行榜、荣誉与分享

| 入口     | 内容与范围                                                                                     |
| -------- | ---------------------------------------------------------------------------------------------- |
| 排行榜   | 积分、有效局数、胜率与趣味榜；默认本月，非积分榜可切换全部，支持并列排名与本人上榜进度         |
| 趣味记录 | 按已知事件统计技能、终局、生存与票选表现；点击次数可回查本人对应对局，未知记录不当作零次       |
| 荣誉徽章 | 18 枚月榜徽章，按当前月公开榜榜首资格动态计算，包含并列榜首；最多佩戴 3 枚，展示在玩家战绩卡中 |
| 月度战报 | 按月查看有效对局、玩家、活跃天数、积分与战绩前三及趣味荣誉；本月实时查看，历史月份按需生成     |
| 图片分享 | 排行榜本人成绩与月度战报可生成图片，预览后发送好友或保存；月报较长时自动分张                   |

微信与开发账号默认公开上榜，可在排行榜底栏关闭；该开关控制公开榜单展示，同房战绩卡仍可查看。游客可查看榜单。已发送的图片无法随公开设置撤回或自动更新。

详细口径见 [趣味记录](fun-records.md)、[月榜荣誉徽章](honor-badges.md) 与 [月度战报](monthly-report.md)。

## 回避卡

回避卡余额跟随账号，初始为 0 张，可由管理员发放或通过有效正式对局累计获得：

| 来源       | 获得方式                                   |
| ---------- | ------------------------------------------ |
| 失利奖励   | 每累计 2 场失利获得 1 张                   |
| 胜利奖励   | 每累计 4 场胜利获得 1 张                   |
| 管理员发放 | 定向发放，或向确认时已存在的非陪测玩家发放 |

胜负分别累计，跨房间、跨月保留，不要求连续。自动奖励仅覆盖功能上线后新开的有效正式对局；不补历史奖励，上线前已发牌的对局也不参与。关闭计分的正常对局仍参与；测试局、陪测账号、旁观者、终止及无有效胜负的记录不参与。

在房间准备区点击“回避卡”，发牌前选择一种不想抽到的初始角色。已准备也可修改或取消，不改变准备状态。系统尽量满足全桌请求，**实际避开才扣 1 张，未生效不扣卡**；成功发牌后终止不退款。中途换牌、抽 B 牌和阵营转换不受影响。

选择与结果仅本人可见，结果随私密身份揭示。发牌后入口隐藏，“我的”和首页不展示余额。收到卡片仅在房间准备阶段提醒，多笔未读合并，确认状态保存在服务端。管理员更正导致应得奖励减少时不追回已发卡，多发部分抵扣后续自动奖励。

## 隐私与公开范围

- **身份由本人主动查看**：小程序不持久化私密身份，进入后台清除展示内容，返回后不会自动重新揭示。
- **房主只看提交进度**：房主也是玩家，没有全员身份或秘密行动查询权限，不能查看未公开的秘密票型和目标。
- **票型按操作公开**：组队票在结算后公开，任务牌只展示汇总；湖中仙女查验仅本人可见。
- **十二骑士过程可选公开**：房主在设置中开启已结算技能过程展示前需确认，默认隐藏；最终出局与复活座位会公示，新身份牌面始终仅本人可见。
- **缺失信息不推测**：未保存的历史身份、过程与结算依据不会从当前状态反推。

开发、接口与发布细节见 [架构与协议](architecture.md) 和 [部署指南](deployment.md)。

## 按月清除个人战绩

在「我的 → 数据管理」选择年份和月份，先查看月份概览，再在底部「核对清理范围」面板中确认清除。面板内可取消，切后台会关闭未提交的确认；只有点击「确认清除」才提交。按北京时间的对局结束月份归属对局，积分调整按发生月份归属；支持当月和已有记录的历史月份，一次清理一个月份。

清理会移除本人该月已有的全部个人对局记录、详情及个人复盘入口，同时移除胜负、角色／阵营战绩、积分及明细、趣味事件次数与机会数（含 MVP／SVP）的统计贡献。月榜、总榜、趣味榜、月度战报及月榜徽章按剩余数据重新计算。其他月份仍有数据时，总榜可能继续保留名次。管理员已隐藏的该月个人记录一并清理，之后恢复共享对局也不会恢复本人记录。

同桌玩家的胜负、积分和共享对局过程保留，他们的复盘仍可包含你的参赛信息。已发放的永久活动徽章、回避卡及累计奖励进度保留。清理属于个人记录管理，原始共享数据和必要清理留痕仍存储于服务端，玩家端不提供恢复。

清理当月后，新结束的对局继续正常累计和参与排名。旧对局的荣誉票选、管理员更正、重新归档和服务重启不会使已清理的个人记录重新出现。清理期间如果数据发生变化，需要重新预览并确认；网络未确认时使用「重试并核对清理结果」，重试原请求不会清除后来新增的对局。
