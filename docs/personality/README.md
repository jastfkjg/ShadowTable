# 阿瓦隆十六人格

「我的」中新增常驻人格卡；网页版入口为 `/personality`。未测试时打开介绍页，有草稿时继续答题，已完成时查看最近一次结果。人格不参与发牌、积分、胜率或荣誉判定。

## 内容来源

当前题库为 v3.2.0，含 10 道短题和 5 道情景题。题库源文件是 `miniprogram/pages/personality/quiz.json`。更新后运行 `node scripts/sync-personality-quiz.js` 生成小程序使用的 `quiz-data.js`。服务端保留 v2.0.0、v3.0.0 与 v3.1.0 题库，按提交版本复算。v3.1 的十六型样例在 v3.2 中仍全部可达。

新版各选项按实际策略重新编码为 -2 至 +2，每题测量一至三项维度。沿用题内中心化、按维度归一、八个角色原型和同分处理。角色使用七项决策维度。E 单独决定 A/B 亚型。未答全或仍需补题时只显示答题流程。样例验证的是结果可达性。

## 答题和恢复

- 15 道独立题目，每题选定后再进入下一题，可返回修改。精确同分最多增加主角色、介入风格两道补题。
- 改动任一主问题会清除旧补题答案，重新计算补题需求。题目与选项按稳定ID保存，不按显示位置计分。
- 本机草稿按账号标识与问卷版本隔离，保存答案、补题、当前位置及本次答卷编号。草稿不跨设备同步；完整结果保存到账号，可跨设备读取。
- 中断后从原题继续；已确认账号且已有本机缓存时，网络故障不妨碍继续作答。本地存储失败会明确提示，不假称已保存。
- 完成后立即在本地展示，后台提交同版本答案，由服务端复算并保存。超时、断网或响应丢失后可使用同一答卷编号重试，不生成重复结果。
- v3.1 未完成草稿可保留全部主问题选择，补题需求按新权重重新计算。v3.0 未完成草稿按稳定 ID 带入新版，重写的第 13 题须重新选择。更早版本的未完成草稿保留在本机，从新版第一题开始。已完成但尚未确认同步的旧版答卷仍可按原版本提交。已保存结果、分享和作答依据保留原有快照。
- 前十题是短题，后五题分行呈现身份、局面信息与当前抉择，并标明情景进度。介入风格的两端选项均衡分布于三个显示位置；掩护倾向通过三个不同局面衡量。情景题采用 10 人标准局及 11 人红蓝兰斯局。题内规定奥伯伦上车只能出失败，刺杀开始后全桌禁言，刺客根据已有信息落刀。第 14 题根据落刀理由只计推理入口 D。

## 结果和分享

结果先展示居中的角色牌，包含蜡笔角色大图、角色名、人格称号和一句描述。本人结果在牌下的「为什么像你」中分别展示支持角色判断和介入风格的真实选择，以第一人称概括，并在作答依据中保留原选项。介入维度的归一分绝对值不超过 0.15 时，角色判断和介入偏好分开说明，并展示答卷中能代表主动、择机的例子。风格精确同分时继续使用实际补题决定称号，原文可在作答依据中查看。角色倾向混合时另提示次接近角色。公开分享以好友视角展示摘要。详细报告展示长处、代价和建议，「本次偏好」直接展示八条坐标轴，每条用一个牌桌情境和两种具体做法标出作答倾向。不提供能力分、稀有度、隐藏类型或匹配率。

主动点击分享后才建立公开快照；快照包含分享时的昵称和人格摘要，不包含原始答案、逐题解释、维度值或账号标识。重新测试不会修改已发送的链接。小程序好友卡片、朋友圈进入页和网页公开链接均支持查看摘要并进入测试；朋友圈单页不读取本地登录状态、不登录、不调用本人接口。

PNG人格卡由小程序和网页共用Canvas渲染器生成，含角色形象、人格称号、描述与项目已有小程序码。小程序码指向桌边助手，图上标注「我的 → 人格」路径；小程序分享链接则直接定位公开人格卡。小程序相册拒绝授权时提供设置入口；网页支持下载与复制公开链接。

本人可查看最近20条测试并打开其中一条；重测保留已保存结果。游客或开发账号的结果绑定其当前账号，清除登录信息后无法自动恢复。

## 接口和存储

| 接口 | 作用 |
| --- | --- |
| `GET /api/me/personality` | 本人账号缓存键、最近结果和最近20条摘要 |
| `POST /api/me/personality/results` | 接收版本、答卷编号、答案和补题，由服务端复算 |
| `GET /api/me/personality/results/:id` | 本人历史结果；其他账号返回404 |
| `POST /api/me/personality/shares` | 本人结果的公开摘要快照，按结果去重 |
| `GET /api/personality/shares/:id` | 无需登录的公开摘要 |

`server/personality.js` 在应用启动时幂等创建 `personality_results` 与 `personality_shares`。沿用现有鉴权、限流、SQLite事务和网页会话保护。结果提交严格校验字段，不接受客户端自报人格。相同账号、同一答卷编号且内容相同返回原结果，内容不同返回409。账号私有接口设置no-store；公开分享使用随机48位十六进制标识。

先部署服务端，再发布小程序；网页资源随服务端发布。新小程序页面位于独立分包，完整题库、页面样式及二维码不进入主包。

## 验证

```sh
npm run test:personality
npm test
npm run check
node scripts/render-personality-preview.js
```

专项测试复算新版全部十六型，并比对归档题库、原始计分及旧版结果。还覆盖题目人数、无效与缺失答案、E 与角色独立、补题、账号隔离、断网恢复、过期响应、幂等保存、重启持久化、公开分享及小程序相册权限反馈。

预览脚本从生产WXML/WXSS生成虚构场景，输出在 `output/playwright/personality/native/`。浏览器检查可覆盖题目、结果、分享、下载和布局；微信原生发送面板、相册授权与最终上传包体积仍应在微信开发者工具及真机发布验收中确认。

新增页面使全部模板的编译输出超过旧预览工具默认的1MiB缓冲区。`scripts/miniprogram-compiler.js` 统一将测试和预览输出缓冲区设为8MiB，不影响小程序运行时或发布包。
