8人三次任务成功后由莫德雷德在线下刺梅林，房主确认线下结算完成，服务端不代判最终胜方。9人复用11人逆仆规则：先指认逆仆再刺梅林。进行中的旧房间保留已发身份，角色说明按实际身份汇总；同房重开使用新配置。

随机洗牌、随机首队长，之后按座位顺时针轮换。梅林看见坏人（不含莫德雷德）及逆仆；派西维尔看见梅林与莫甘娜但无法区分；睁眼坏人互见同伴座位与具体角色，但不见奥伯伦，奥伯伦不见同伴；逆仆只见刺客且只能投成功；忠臣无额外初始信息。

阶段：身份确认 → 队长提名 → 房主开启组队表决 → 全员提交赞成/反对 → 房主公开结算 → 通过则房主开启任务 → 队员秘密出牌 → 房主结算任务 → 结果展示 → 房主开启下一轮或刺杀 → 刺客选目标 → 房主结算 → 结束。

队长可以选自己；队伍必须恰好等于人数表、不能重复。组队表决严格过半通过，平票否决；结算前所有票保密，结算后按座位公开赞成/反对。连续5次否决坏人胜；通过时否决计数归零。任务仅队员出牌，好人只能成功，坏人成功或失败。秘密票汇总计数，不公开票与玩家的对应。通常至少1失败即失败；7人及以上第4任务至少2失败才失败。3任务失败坏人胜；3成功进入刺杀，刺客指认一位好人中的梅林，命中坏人胜，否则好人胜。

不使用提前起刀、空刀、守护、角色交换、湖中仙女或扩展牌。目标是玩家座位，身份全局不变，行动按本人当前角色验证；多人任务票在全员提交后一次性合并，提交不允许撤回。房主不能绕过完整提交。无强制倒计时；断线保留座位和提交，可恢复登录；房主可终止对局（不判阵营胜负），同房重开重新准备、重新随机分配。

隐私策略：结束或终止也不新增全员身份披露；仅返回胜方/原因及公开历史。房主和普通玩家使用同一视图构造器；秘密阶段不返回他人提交状态、进度、更新时间或因秘密提交变化的公共版本。自己的身份和初始视野单独按需读取，小程序不持久化。

## 扩展文档解析（完整自动规则尚未启用）

### 影中执刃（12人）

配置7蓝：梅林、派西、忠臣×4、蓝内奸；5红：莫德雷德、莫甘娜、刺客、奥伯伦、红内奸。莫德雷德/莫甘娜/刺客互认但不知角色；奥伯伦互不认识；红内奸单见莫甘娜/刺客/奥伯伦但不知角色；梅林见红内奸不见蓝内奸。其他视野细节待确认。
流程明确部分：组队→车上暗投→开票；奥伯伦/红内奸必失败、蓝内奸必成功。3失败红胜；3成功后涉及优先盘刀。红内奸先猜全体坏人及身份，猜错让坏人继续刺杀，猜对再独立刺梅林，刺错红方与内奸失败。蓝内奸挡刀且上车≥2次并在决胜车可独赢；优先级蓝内奸>红内奸>阵营。具体挡刀触发、提前起刀、表决/平票/人数/保护轮等见问题表。无文中明示身份交换或守护技能。

### 混沌契约（12人）

6蓝：梅林、派西、忠臣、蓝术士、高文、捣蛋鬼；4红：莫德雷德、莫甘娜、红术士、奥伯伦；2第三方：蓝/红盗贼。盗贼互认；高文见两术士；梅林见红盗贼、不见蓝盗贼和捣蛋鬼。捣蛋鬼首夜选2人绑定胜负，同阵营随该阵营，不同则随蓝且被刺可能独赢。
明确流程：首夜捣蛋鬼→组队→任务→开票→3蓝后盗贼优先刺坏人→匪队刺梅林。术士成功或魔法，不可失败；高文/蓝盗贼/捣蛋鬼只能成功；红盗贼只能盗贼失败；奥伯伦必失败。1魔法反转、2魔法不变；普通轮盗贼失败禁止反转；第4轮盗贼失败计1失败且可反转。盗贼参与过任务人数0/1/2对应猜中4/3/2坏人目标要求（原文详见快照）。盗贼>捣蛋鬼>阵营排名。3失败与混合排名、合并刺杀、基础票型和具体披露待确认，不可计算最终胜负。无文中明示身份交换或守护。

### 十二骑士（12人）

A牌7蓝：蓝刀客×3、忠臣×2、派西、梅林；5红：红刀客×2、刺客、莫德雷德、莫甘娜。B牌7蓝/5红按原文分3层混洗（2红2蓝 / 2红3蓝 / 1红2蓝）。全部角色、技能与初始视野见快照，不用其他桌游补齐。
阶段：任务→第2–5轮转换→技能（队长起依序即时结算）→技能结束按序抽B复活→第2–5轮仙女→第2–5轮夜晚先知。新B技能下一轮生效。复活甲把首次B抽牌转为原视野牌、无技能。B耗尽出局者不能投票/上车但可发言，保留最后阵营。
兰斯洛特文字明确「阵营互换」，魔术师文字明确「号码交换、本轮按交换后的号码结算」，不能解释为交换整张角色卡。转换牌2转换5不转换混洗依次抽。守卫→女巫替代→猎人/圣骑士是已知优先级；与顺序即时技能如何整合未明。3失败红胜；3成功再刺梅林/空刀，命中红胜。可提前起刀、红方多数决议、平票猜拳选带刀人。涉及目标寻址、已提交动作、公开信息、连锁死亡、空刀及复活时点的缺失见问题表。

## 影中执刃·线下结算辅助（可选的有限范围）

用户明确将初始互认、内奸挡刀/猜角色/起刀等交在线下，后续疑问记录并跳过。因此完整 `shadow-blade` 自动规则模式仍禁用，新增 `shadow-assist` 辅助模式。

辅助模式的线上部分：随机首队长、座位顺时针轮换；组队表决、平票与任务人数按确认后的共同规则；蓝方成功，奥伯伦及红内奸必须失败，其余红方成功/失败；第4轮双失败，其他轮单失败。组队票结算后按座位公开、任务只公开汇总，不返回个人暗票。

三成功、三失败、5次否决都会进入线下特殊结算，不在软件内宣布最终胜方。房主也可因线下起刀转入该状态，停止线上任务，未结算暗票不披露、不影响已完成任务记录。特殊规则及最后胜方在线下处理；房主只确认「线下已完成」，服务器结束本局（winner=null、明确说明没有自动判胜），可同房重开。该模式不提供守护、身份互换、内奸目标合并或排名按钮，不用假规则填空。
