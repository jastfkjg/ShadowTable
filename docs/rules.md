## 按需工具流程（2026-09-14用户确认）

小程序发牌默认进入等待房主发起操作，不强制身份确认、组队、投票、任务和刀人的先后顺序。已有顺序流程房间可在结算或发起工具时切换，保留已发身份。

- **投票**：全员投赞成/反对，可附带所选队伍，也可用于独立线下议题；结算后公开座位票型和是否过半，不自动推进任务或判整局胜负。
- **任务**：房主选择任意非空队伍、1或2张失败票门槛。保留当前角色的出牌限制；只有队员提交，其他玩家不需确认。公开任务结果和失败总票数，不公开玩家与票的对应。
- **刀梅林**：由刺客在本人手机选择目标，房主结算后记录目标与是否命中，不自动结束本局。8人无刺客配置继续由莫德雷德在线下刀梅林；线下辅助板的特殊刀人在线下完成。
- **刀逆仆**：有逆仆的配置可独立发起，由刺客操作；目标和命中保持私密，命中后的阵营变更只影响对应玩家。结算后可自由发起下一操作。
- **作废与结束**：未结算操作必须明确确认作废后才可切换或结束；旧阶段请求被拒绝。房主结束本局只记录结束，以线下胜负为准。同房重开才重新分配身份。

每次操作使用独立阶段编号、提交集和公开记录。房主可查看逐玩家的完成状态，但不可查看具体提交内容。刀人环节非刺客也需确认，使完成状态不区分角色。下文的固定顺序推进保留用于旧客户端兼容，不限制小程序的按需工具流程。

阶段：身份确认 → 队长提名 → 房主开启组队表决 → 全员提交赞成/反对 → 房主公开结算 → 通过则房主开启任务 → 队员秘密出牌 → 房主结算任务 → 结果展示 → 房主开启下一轮或刺杀 → 刺客选目标 → 房主结算 → 结束。

队长可以选自己；队伍必须恰好等于人数表、不能重复。组队表决严格过半通过，平票否决；结算前所有票保密，结算后按座位公开赞成/反对。连续5次否决坏人胜；通过时否决计数归零。任务仅队员出牌，好人只能成功，坏人成功或失败。秘密票汇总计数，不公开票与玩家的对应。通常至少1失败即失败；7人及以上第4任务至少2失败才失败。3任务失败坏人胜；3成功进入刺杀，刺客指认一位好人中的梅林，命中坏人胜，否则好人胜。

不使用提前起刀、空刀、守护、角色交换、湖中仙女或扩展牌。目标是玩家座位，身份全局不变，行动按本人当前角色验证；多人任务票在全员提交后一次性合并，提交不允许撤回。房主不能绕过完整提交。无强制倒计时；断线保留座位和提交，可恢复登录；房主可终止对局（不判阵营胜负），同房重开重新准备、重新随机分配。

隐私策略：结束或终止也不新增全员身份披露；仅返回胜方/原因及公开历史。房主和普通玩家使用同一视图构造器；普通玩家不获取他人提交状态；房主只额外获取完成状态及计数，不获取票型、目标或角色。自己的身份和初始视野单独按需读取，小程序不持久化。

### 十二骑士操作顺序

发牌后可按线下进度做任务。第1轮可直接“使用技能”；第2–5轮先“身份转换”，再“使用技能”。技能结束自动按出局顺序抽取分层混洗的B牌，复活甲消耗一张B牌恢复原视野身份且无技能。新B技能在“进入下一轮”后生效。B牌耗尽后出局者不能参加投票/任务，可发言并参与统一技能确认。

第2–5轮技能后可发起“仙女查验”和“夜晚”。查验只发给持有者，随后传递仙女；先知在本人身份卡读取该夜在场B牌坏人座位。初始视野固定在发牌时，后续死亡/换身份不会自动更新初始互认。

所有人同时在手机提交一个技能或“不使用技能 / 确认”。守护未触发不消耗，下轮可重选；女巫替死能被守护，替死者不触发猎人枪。猎人出局时插入全员确认环节，仅猎人有开枪选项，收齐后继续剩余技能。技能记录只公开开刀/开枪/复活及出局结果，不公开防护、替死和换号提交，不公开出局或抽取的身份。

技能或查验进行中需先结算，或明确“作废当前操作”才能切换。技能中途作废恢复该技能环节开始时的角色、存活、技能次数和牌堆；已经看到的信息无法撤回，线下应仅在误操作时作废。旧阶段请求被拒绝。

最终刀：房主选择线下多数决议的红方带刀人，平票先在线下猜拳；带刀人本人录入目标或“0号空刀”，其余人确认。服务端记录是否命中当前在场梅林/是否场上没有梅林。三任务成功前只允许存活见面匪提前起刀，发言环节由线下确认；三成功后可以选当前红方成员。仍由房主结束本局，不自动锁死后续工具。

### 混沌契约任务

蓝/红术士可成功或魔法；蓝盗贼仅成功、红盗贼仅盗贼失败、奥伯伦仅失败，其余按角色阵营限制。盗贼属于独立第三方。普通轮盗贼失败强制失败且禁止反转；两失败门槛的保护轮盗贼失败计1失败，奇数魔法反转、偶数魔法不变。公开成功、失败、盗贼失败、魔法四类总票数，绝不公开出牌人。
