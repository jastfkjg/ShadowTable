# 月度战报

入口：小程序及网页版「我的 → 月度战报」，与「排行榜」并列。默认直接显示当前月份的完整榜单，不再区分摘要和折叠详情。可选择有历史记录以来的月份，本月数据实时更新。

## 内容与排名

- 概览只展示有效对局和参赛玩家，两项均去重统计。概览含未公开及游客的有效参赛记录，个人榜单只展示已公开的微信和开发账号；接口保留活跃天数统计，页面和分享图不展示。
- 主榜展示积分榜、战绩榜前三。页面、完整月报和分享图都跳过没有上榜玩家的榜单，连同标题一起隐藏；没有趣味荣誉时也不显示该分组标题。积分包含当月有效计分局与当月独立积分调整，至少一场计分局才有资格，零分计分局保留。对局更正仍归原对局结束月份，独立调分归操作月份。
- 战绩榜按总胜率排序，至少 10 场有效对局；完整月报提供局数榜（桌边常驻王）、好人胜率榜和坏人胜率榜。阵营胜率也各要求 10 场对应阵营对局。月报门槛独立于现有排行榜，不改变现有榜单规则。
- 趣味榜复用已归档趣味指标，跨玩法汇总。次数榜至少一次对应记录；接口保留的成功率／发生率榜要求至少 5 次已知有效机会。未知记录不当作零次，也不进入分母。零成功但有足够机会的玩家可以进入比例榜。
- 分享图按综合榜单、趣味荣誉、娱乐榜的顺序展示全部有记录的榜单，不再限制精选三项荣誉；空榜及对应空分组隐藏。趣味榜以次数为主值，成功率／发生率及机会数随玩家一起展示，不重复附加比例榜。完整月报使用统一的十一项技能／终局称号及统计口径，包含金牌替身，详见 [趣味记录](fun-records.md)。
- 竭尽全力、舍我其谁、背锅侠、卧龙凤雏、痛击队友单列为娱乐榜。月报页面的趣味荣誉和娱乐榜均固定按次数展示，不显示排序切换栏；导出时与其他榜单合并到同一张完整长图，不再区分娱乐版。
- 小程序与网页版采用 A 方案：导航保留“月度战报”，132px 月夜圆桌头图内以年份和大号月份选择器代替重复标题，本月标注“本月实时更新”，历史月份标注“完整月报”。64px 概览显示有效对局与参赛玩家，右侧信息按钮打开统计口径。综合榜单、趣味荣誉、娱乐榜三个页签切换后展示对应完整列表。
- 所有页面榜单统一使用头像、金／银／铜月桂名次、并列标记和右侧数值；20px 圆角榜单内采用紧凑标题与至少 64px 的玩家行，榜首成绩使用暖金色。趣味次数榜昵称下显示“成功率／发生率 33.3% · 3 次机会”。积分榜副标题为“本月积分”，仍按原口径包含积分调整。
- 分享入口固定在底部并适配安全区，列表预留底部空间，全部并列玩家仍可滚动查看。三个页签统一提供“生成月报分享图”，导出内容不受当前页签影响；旧的娱乐版分享链接也归一化为完整月报。空月隐藏分享入口。页面不展示重复大标题、本月高光、底部时间／版本及重复规则入口；统计规则和发送、保存流程保持原实现。

积分、局数、趣味次数相同则并列。比例按原始整数分子／分母比较，未舍入比例相同时样本更多者优先；比例及样本都相同时并列。采用现有竞赛排名口径，如 `1、1、3`；保留名次不超过 3 的全部玩家，不受排行榜前 100 行上限限制。不足三人时按实际人数显示。

## 月份、版本与公开范围

统计按北京时间自然月的半开区间 `[月初零点，下月初零点)`，以对局结束时间归属。无有效对局时显示空态，不能生成空月报图片。不支持未来月份。

月报按需生成：无需额外定时任务，月份结束后首次查看即产生完整月报。历史记录可以直接查询。内容由服务端从有效战绩、有效计分及已知趣味记录计算，一句话高光使用确定性模板，不调用 AI 服务。

`monthly_reports` 表只保存月份、版本、内容指纹、首次生成时间与更新时间，不保存旧玩家姓名或旧月报快照。内容没有变化时保持版本；胜负、积分、记录状态、昵称、头像、公开设置等变化影响内容时，重新读取自动递增版本。服务端重启保留版本。当前公开设置作用于所有月份，关闭后重新查看或重新生成图片不会展示该玩家；已发送图片无法撤回或同步更新。

服务端缓存最多 24 个月、30 秒，沿用战绩和公开资料变更的排行榜修订号即时失效。接口需登录，游客可查看；响应 `Cache-Control: no-store`，不返回账号 UID、牌桌昵称、角色身份、对局明细或技能目标。

## 分享图片

小程序使用现有 Canvas 2D 分享页，原生发送好友或保存相册流程保持一致。分享页采用 A「统一精修」方案：顶部为“完整长图”和可点击的“点图放大”，长图左右各留 12px，底部发送／保存按钮各至少 48px，配统一线条图标并适配安全区。加载、重试、不支持直接发送及相册权限失败时仍使用原有处理流程。

网页版与小程序使用同一份绘制代码。导出长图沿用月夜圆桌、深蓝暖金和衬线主标题，月份不重复显示；概览为数字与标签横排，综合榜单、趣味荣誉和娱乐榜用连续编号的章节分隔。全部榜单统一圆角卡片、金／银／铜月桂名次、头像、昵称旁的并列标记及右侧成绩；昵称字号 46px、成绩 81px，趣味荣誉的成功率／发生率与机会数合并到昵称下方一行。标题、副标题、长昵称及辅助信息按内容换行，超宽数值移到下一行，保留所有文字和全部并列玩家。

背景复用本地圆桌、月夜与城堡素材（约 135 KiB），页尾复用同图的森林部分。素材加载失败时仍可使用纯色背景生成图片，头像失败显示昵称首字。图片保留月份、日期区间、实时更新提示、品牌及统计截至时间，不展示版本或公开范围说明。每份月报始终生成一张完整长图；逻辑宽度 1080px、高度随内容增加，超过 8192px 时整体等比缩小画布，不分页、不删除尾部荣誉。分享页等宽纵向滚动，点击图片或放大入口使用原生图片预览。

## 接口与发布

`GET /api/monthly-report?month=2026-09`，省略 `month` 为本月。只接受一个合法的 `month` 参数。

响应包括 `month`、`currentMonth`、`firstMonth`、`periodStart`、`periodEnd`、`timezone`、`status`、`rulesVersion`、`version`、`generatedAt`、`updatedAt`、`asOf`、`overview`、`mainBoards`、`funBoards`、`featuredIds`、`highlights`。每榜包含前三名次的全部公开玩家、单位、门槛和总符合条件人数。趣味次数与比例分别返回，不共享可变排名对象。

新增 SQLite 表在服务启动时创建，无需人工迁移。先部署服务端，再发布小程序；新客户端遇到旧服务会显示明确的未开放提示。网页版文件随服务端一起更新。本功能不需要部署新的外部服务。

## 验证

- `npm test`：覆盖月界／闰年／跨年、有效状态、公开资格、计分与调整、样本门槛、原始比例、并列、未知趣味记录、版本及重启、接口鉴权、月份切换与后台旧响应，以及完整长图、超长画布缩放和发送／保存。
- `npm run check`：语法检查。
- `node scripts/render-monthly-preview.js`：使用生产 WXML/WXSS 与共享 Canvas 绘制代码生成 `output/playwright/monthly/` 预览，包含正常、娱乐榜、稀疏战绩、空月和长昵称场景。

浏览器视觉验证可以检查原生模板的布局投影，但微信月份选择器、Canvas 导出和发送／相册权限仍需要微信开发者工具或真机验收。

背景素材的生成方式与提示词记录见 [月报美术素材](monthly-report-artwork.md)。
